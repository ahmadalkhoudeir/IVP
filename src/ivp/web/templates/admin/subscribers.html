Channel enrollments

Hard requirement 2: confirmation channels must be enrolled here, before any call — nothing on a ticket lets an agent supply or change a destination. This page is intentionally not linked from anywhere in the ticket flow.

Adding a channel for a subscriber who already has one sends a notice to every existing channel (NIST SP 800-63B-4 §4.1.2.1) and holds the new channel in a {{ "%g"|format(cooling_off_hours) }}-hour cooling-off period before it can be used for verification. A subscriber's first channel is usable immediately, since there is nobody to notify. Every enrollment is written to the audit log.
