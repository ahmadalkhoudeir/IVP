Channel enrollments

Hard requirement 2: confirmation channels must be enrolled here, before any call — nothing on a ticket lets an agent supply or change a destination. This page is intentionally not linked from anywhere in the ticket flow.

Simplification for this demo: enrolling a new channel takes effect immediately. A production system should also notify any existing enrolled channels when a new one is added, with a cooling-off period before the new channel becomes usable — see docs/threat-model.md (Spoofing: attacker asks to change the enrolled channel).
